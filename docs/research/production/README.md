# Industry Production Knowledge Research Library (Layer 3)

Layer 3 grounds the AI Drama System in real film, television, and animation production practice.

AI research explains generation methods.

Production research explains the professional domain the software is intended to model.

Production practices inform domain design but do not automatically become software requirements.

This layer preserves the canonical hierarchy:

Project -> Story -> Episode -> Scene -> Shot

It does not replace canonical units with panel, keyframe, setup, take, or sequence.

## Traceability Flow

Primary Production Source
-> Production Research Record
-> Production Research Principle
-> Candidate Requirement
-> Domain Specification
-> ADR (if required)
-> Implementation
